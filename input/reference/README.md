# Small public numerical references

These files are released as CC BY 4.0; see `../../DATA_LICENSE.md`.
They are numerical inputs, not private raw cycling workbooks.

- `theoPracCapNeg.mat` and `theoPracCapPos.mat` contain scalar `Q_r` in **mAh**,
  before multiplication by the configured active-material fraction. They are
  unchanged copies of the previous capacity reference files. The calculation
  and assumed coating masses/host-mass convention are in `modelElectrodeCapacities.m`.
- `ocpReferences.mat` contains `negative`, `positive`, and `provenance`.
  Each reference has `thetaAbsolute`, `thetaRelative` [-], and `voltage_V` [V],
  all matching column vectors copied without resampling from the average LUT.
  Provenance identifies the source MAT files by basename and SHA-256.

These are the existing outputs, not new fits generated by the preparation.
The companion modelOCV article uses an older frozen snapshot: its average
potential arrays match, but its positive absolute coordinate differs by up to
about 0.0041244. Do not claim identical calibration across those snapshots.

Absolute calibration depends on the adopted MSMR/endpoint and correction
assumptions. It is not independently validated by a small fitting residual.
Regenerating these models requires the private workbook inputs and an explicit
review of fitting diagnostics, final calibration and manuscript correspondence.
